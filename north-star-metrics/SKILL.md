# Agent 北极星指标

**outcome 的形状由「翻了哪一格」决定，不由品类惯例决定。**

先用 [agent-positioning](../agent-positioning/SKILL.md) 定位它翻了哪几格，
再回来查下表。

这是 agent 产品版。通用的北极星指标方法见 lenny-skills 的 `north-star-metrics`。

## 翻哪一格 → 指标换什么形状

| 翻了 | outcome 必须变成 | 作废的旧指标 |
|---|---|---|
| 只换用户群，参数没翻 | 新人群的**整活交付率**（能不能把一整个活交出去） | 满意度、使用频次 |
| **在场人数 → 多人** | 能**归因到团队**的产出 | 一切人均指标 |
| **判断权 → agent** | **产出份额** = 它产出的 ÷ 该类工作总量 | **DAU / 会话数 / 时长——全部作废** |
| **记忆 → 常驻** | 好处之外必须加一条**「记错的代价」** | 只报召回命中率 |

**第三行是硬失效，不是「不太合适」。** DAU 这类指标的前提是「用户来了」；判断权翻给 agent
之后，用户不来它也在干活——前提消失，指标不是变差，是**不再度量任何东西**。

基准刻度：一个已上线产品报的成绩是「产品组 **65% 的 PR 由它写**」，不是「每天多少人 @ 它」。
那个参数位置上，只有这一类数字还成立。

## 结果侧判据：加法还是减法

机制侧要看得到实现才能判，结果侧从外面就能判——**能拿去拆竞品**。

| | 输出是 | 用户的动作 | 替你说过「不」吗 |
|---|---|---|---|
| **省手** | 素材（下好的简历、填好的表） | 工作量↓，**决策次数不变** | 没有，全推给你 |
| **省判断力** | 结论（这 3 个值得聊，其余否了） | **决策次数↓**，时间非线性下降 | 有。**分界线在此** |

**省手只做加法，省判断力敢做减法。** 一句话检验：**它替你说过「不」吗？**

一个把所有输入都处理完、全量推给你的 agent，无论动作层做得多深，结果侧看仍是省手——
你的决策次数一次没少。

## 份额必须配误否率

> 「误否率」= 它否掉的里面，有多少是你本来会要的。
> （别叫它「弃真率」——那是统计学词，隔一夜就忘，读者会脑补错方向。）

```
说错「是」→ 做了件蠢事
            代价可见、可回滚、你会知道
说错「不」→ 否掉了一个本该要的
            代价不可见 —— 你永远不知道错过了谁
```

**没有误否率，份额越高越可疑**——它可能靠大量误否把分母做小。

误否率不可测的场景（被筛掉的候选人不会回来说「你本该聊我」），这件事本身是个发现：
**它给「能委托多少减法」定了上限，而这个上限由「误否浮出水面的概率」决定，不由模型能力决定。**

## 先分清它是哪一类委托——指标形状完全不同

| | 委托判断型 | 委托在场型 |
|---|---|---|
| 主指标 | **产出份额** = 它产出的 ÷ 该类工作总量 | **覆盖率** = 多少比例的请求在 N 分钟内被响应 |
| 配套 | **误否率**（它否掉的里有多少本该要） | **转化率**（多少比例达成了目标动作） |
| 失败构成 | 按决策错误分类 | 按**答错 / 该转未转 / 漏收集**分类 |
| 不适用 | — | **误否率**——在场型岗位通常不做否决 |

**在场型岗位的价值是 availability，不是 judgment**，所以拿份额去量它会量错东西：
它本来就该处理所有请求，份额接近 100% 是设计目标，不是成绩。

## 测校准，不只测正确

```
正确 = 判对了吗
校准 = 它对自己的确信度准不准
```

一个 80% 准确但确信度乱标的 agent，比 70% 准确但知道自己何时不确定的**更难委托**——
后者能自己触发人在环，前者不能。**校准是判断权能被授予的隐藏前提。**

evals 在这里的作用不是提高准确率，是**把判断变得可预期到敢授权的程度**。

已上线产品的做法：关键判定带 `confidence: high|low`；录真实模型调用回放做回归。

## 不看总失败率，看失败的构成

一个已上线产品把记忆合成的**五种失败态各自计数**，时效类与出处类分开看。

**分开计数才知道该修哪道闸。** 总失败率是一个不能指导行动的数字。

## 收口

**做完 = 报的每个数都能回答三问**：
```
它对应哪一格的翻转？        （翻了判断权还报 DAU = 这个数已作废）
它是投入侧还是产出侧？      （产出侧才算数）
它的误否率是多少？不可测的话，能否的上限卡在哪？
```
